# Keystone Frontend

This directory will hold the Keystone AI frontend, developed separately from the backend.

## Status

Not yet started. The frontend is out of scope for the current same-day backend prototype step.

## Planned stack

- React or Next.js (decision pending)
- Communicates with the backend via the REST API described in [`../docs/api-contract.md`](../docs/api-contract.md)

## Local backend URL

During local development, the backend runs at `http://localhost:8000` (see [`../backend/.env.example`](../backend/.env.example) for CORS configuration).
